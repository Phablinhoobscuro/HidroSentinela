# HidroSentinela
Repositório do Projeto Integrador de Extensão da Instituição Unisales

Visão Geral
O projeto propõe o desenvolvimento de um sistema acadêmico para monitoramento e análise de riscos relacionados a enchentes e inundações no estado do Espírito Santo.
 A solução busca integrar diferentes fontes de dados públicos, como informações sobre precipitação, níveis de rios, condições meteorológicas e ocorrências históricas de desastres, permitindo analisar a situação atual e identificar condições associadas ao aumento do risco em determinadas regiões.
 Como principal recurso, o sistema contará com uma interface geográfica baseada em mapa, permitindo visualizar regiões monitoradas, níveis estimados de risco e informações relacionadas às condições hidrometeorológicas. O usuário também poderá consultar o histórico de ocorrências e de variáveis ambientais de uma determinada região, possibilitando comparar a situação atual com eventos anteriores.
 A partir dos dados integrados, poderão ser utilizadas técnicas de aprendizado de máquina e análise de dados para produzir uma estimativa experimental de risco para uma região e determinado horizonte temporal. A estimativa deverá apresentar, sempre que possível, os principais fatores considerados pelo sistema, contribuindo para uma interpretação mais transparente do resultado.
 O sistema também poderá disponibilizar alertas informativos quando forem identificadas condições de risco, porém sua finalidade principal será fornecer uma visão integrada dos dados e auxiliar na análise e compreensão da situação.
 É importante destacar que o projeto possui caráter acadêmico e experimental e não pretende substituir os sistemas oficiais de monitoramento, previsão e alerta de desastres. O objetivo é investigar como diferentes fontes de dados e tecnologias podem ser integradas para apoiar o monitoramento, a análise de risco e a tomada de decisão relacionados a enchentes e inundações no Espírito Santo.
